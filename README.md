# University Insight

Welcome to University Insight, your go-to platform for exploring and applying to top universities around the world, especially for MBBS courses. This project showcases a responsive and interactive website to help students find the best study abroad options.

## Project Overview

University Insight is designed to provide students with detailed information on studying MBBS abroad in countries such as Russia, Uzbekistan, Kazakhstan, and more. The website features a user-friendly interface, interactive components, and essential resources for prospective students.

## Features

- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Interactive Navigation**: Dropdown menus for easy access to information.
- **Course Finder**: Helps students find courses and universities based on their preferences.
- **Country Highlights**: Showcases top countries for studying MBBS abroad.
- **Admission Process**: Guides students through the steps of the admission process.
- **Popup Form**: Allows students to submit their details and inquiries.

## Technologies Used

- **HTML**: Structure of the website.
- **CSS (Tailwind CSS)**: Styling and layout.
- **JavaScript**: Interactive components and functionality.
- **Google Tag Manager**: Analytics and tracking.
- **Google Fonts**: Custom fonts for enhanced design.

## Setup and Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/satyendra9580/University_Insight.git

2. Navigate to the project directory:
   ```bash
   cd University_Insight
   
3. Open index.html in your preferred web browser.

## Usage
Visit the University Insight website to explore universities, find courses, and get information on studying MBBS abroad. Use the navigation menu to browse different sections, and fill out the popup form to submit your inquiries.
